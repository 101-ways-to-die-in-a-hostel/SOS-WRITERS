## 12 Weeks Before Launch

### Manuscript
- [ ] Final manuscript complete
- [ ] Self-editing pass complete
- [ ] Manuscript sent to developmental editor
- [ ] Developmental edit complete
- [ ] Revisions from dev edit complete

### Cover
- [ ] Cover brief sent to designer
- [ ] Cover concepts received
- [ ] Cover approved
- [ ] Cover files received (all formats)
- [ ] 3D mockups created

### Planning
- [ ] Launch date confirmed
- [ ] Pre-order strategy decided
- [ ] Launch team assembled
- [ ] Marketing budget allocated

---

## 8 Weeks Before Launch

### Editing
- [ ] Manuscript to copy editor
- [ ] Copy edit complete
- [ ] Copy edit revisions complete
- [ ] Manuscript to proofreader
- [ ] Proofread complete
- [ ] Final proofread revisions complete

### Production
- [ ] eBook formatting complete
- [ ] Print formatting complete
- [ ] ISBN assigned
- [ ] Copyright registered
- [ ] eBook files tested on multiple devices
- [ ] Print proof ordered

### Pre-Launch
- [ ] Book description written (short, medium, long versions)
- [ ] Author bio updated
- [ ] Categories researched
- [ ] Keywords researched (7 for Amazon)
- [ ] Comparison titles identified
- [ ] A+ Content created (if applicable)

### Marketing Prep
- [ ] Press release written
- [ ] Media kit assembled

- [ ] NetGalley listing (if using)
- [ ] BookSirens listing (if using)
- [ ] Reviewer list compiled
- [ ] Blogger outreach list compiled
- [ ] Podcast outreach list compiled

### Content Creation
- [ ] Blog posts scheduled
- [ ] Newsletter content written
- [ ] Social media graphics created
- [ ] Book trailer created (if using)
- [ ] Character art created (if using)
- [ ] Quote graphics created

## 1 Week Before Launch

### Final Preparations
- [ ] All ads scheduled to go live
- [ ] Social media posts scheduled
- [ ] Blog tour dates confirmed
- [ ] Podcast appearances scheduled
- [ ] Launch day schedule planned
- [ ] Support team briefed

### Verify Everything
- [ ] Buy links working

## Launch Day

### Morning
- [ ] Check all links are live
- [ ] Price check all platforms
- [ ] Send launch email to list
- [ ] Post on all social media platforms
- [ ] Activate paid ads
- [ ] Notify launch team

### Throughout Day
- [ ] Monitor sales dashboard
- [ ] Respond to social media comments
- [ ] Share reader screenshots/posts
- [ ] Check for and address any issues
- [ ] Thank supporters publicly

### Evening
- [ ] Document day's sales numbers
- [ ] Screenshot any rankings achieved
- [ ] Schedule tomorrow's content
- [ ] Thank launch team
- [ ] Personal celebration!

---

## Week 1 After Launch

### Monitoring
- [ ] Track sales daily
- [ ] Monitor reviews (don't respond to negative)
- [ ] Track ranking fluctuations
- [ ] Monitor ad performance
- [ ] Adjust ad bids as needed

### Promotion
- [ ] Continue social media posting
- [ ] Send follow-up emails
- [ ] Reach out to additional reviewers
- [ ] Pitch to remaining podcasts
- [ ] Run any planned promotions

### Admin
- [ ] Document lessons learned
- [ ] Update sales tracker
- [ ] Screenshot and save reviews
- [ ] Update marketing materials with reviews
- [ ] Plan next month's marketing

---

## Week 2-4 After Launch

### Sustained Marketing
- [ ] Maintain consistent social presence
- [ ] Continue/adjust ad campaigns
- [ ] Monitor KENP reads (if KU)
- [ ] Plan first promotional sale
- [ ] Pitch for features/newsletters

### Reviews
- [ ] Follow up with ARC readers who haven't reviewed
- [ ] Add reviews to marketing materials
- [ ] Create quote graphics from reviews
- [ ] Update product descriptions with quotes

### Audiobook (if applicable)
- [ ] Begin audiobook production
- [ ] Audition narrators
- [ ] Record sample chapters
- [ ] Finalize production timeline

## Month 2-3 After Launch

- [ ] Analyze what marketing worked

- [ ] Apply for additional promotions

### Next Book
- [ ] Begin outlining next book
- [ ] Set writing schedule
- [ ] Plan next launch date
