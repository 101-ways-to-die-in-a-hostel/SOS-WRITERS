## Technical Specifications

### Resolution
- Print: 300 DPI minimum
- Web: 72-150 DPI
- Minimum dimensions: 2000px on longest side

### Format
- Source files: PNG with transparency
- Web versions: JPG or WebP
- Working files: PSD/AI if applicable

### File Naming
```
101ways-[slug]-char-[character]-[pose].png
```
Examples:
- `101ways-faulty-electrical-char-victim-portrait.png`
- `101ways-faulty-electrical-char-victim-fullbody.png`
- `101ways-faulty-electrical-char-marcus-typing.png`

## AI Generation Notes

### Recommended Tools
- Midjourney (photorealistic, stylized)
- DALL-E 3 (detailed prompts)
- Stable Diffusion (consistency with LoRA)

### Consistency Tips
- Use seed numbers for character consistency
- Reference same prompt base for each character
- Generate multiple and select best matches
- Consider training LoRA for main characters

### Negative Prompts
```
[gore, blood, explicit content, nudity, copyrighted characters, watermarks, text]
```
