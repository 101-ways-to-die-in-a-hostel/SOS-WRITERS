## Technical Specifications

### Resolution
- Print: 300 DPI minimum
- Web: 72-150 DPI
- Minimum: 3000px on longest side

### Aspect Ratios Needed
- 16:9 (cinematic/web banner)
- 4:3 (standard)
- 1:1 (social media)
- 9:16 (stories/vertical)

### Format
- Master files: PNG/TIFF
- Web: JPG/WebP
- With/without color grading versions

### File Naming
```
101ways-[slug]-loc-[location]-[variant].ext
```
Examples:
- `101ways-faulty-electrical-loc-hostel-exterior-night.jpg`
- `101ways-faulty-electrical-loc-bathroom-setup.jpg`
- `101ways-faulty-electrical-loc-bangkok-street.jpg`
