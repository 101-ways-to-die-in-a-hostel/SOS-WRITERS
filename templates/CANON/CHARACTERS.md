# Supporting Characters

## Overview

This document defines all supporting characters who interact with the victim throughout the story. Each character should serve a purpose in either:
- Advancing the plot toward the death
- Providing warnings the victim ignores
- Adding dark comedy or horror elements
- Creating emotional stakes
